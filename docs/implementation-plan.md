## 性能与设备验收办法

Phase 2先选至少一台实际低端Android设备及一台当前设备，记录型号、系统、屏幕、刷新率，不凭模拟器成绩下结论。使用可见最大地图/最多实体/战斗特效构建测试场景；记录帧耗时分位数、输入延迟、分配/GC和后台恢复。

临时工程预算可用60Hz呈现下帧耗时p95不超过16.7ms作为目标，**不是已经测得的性能，也不是原游戏速度定义**。若设备或画面基准不支持这个目标，用实际测量修订预算；不能加速逻辑补偿绘制掉帧。

图像对照需要记录基准分辨率、色板、裁边和截图时间点；不做任意拉伸后再计算误差。完全相同像素未必适用于来源不明的复刻图，所以优先先确定原版资产基准。

## 阶段完成门禁

- 可构建不等于可游玩；资源数量不等于原版覆盖。
- 每阶段产物必须能运行或验证，报告实际执行命令、结果和未执行项。
- 新内容出现UNKNOWN时阻止该内容进入verified包，可继续无依赖工作。
- 数据/资源来源和许可证单独审核；私人研究提取不自动升级为公开发布许可。
- 真实ROM只在本地、Git忽略路径，公开CI不获取、不上传、不要求ROM下载。
- 每阶段结束产出可读差异与验收证据，再由用户决定继续范围。
