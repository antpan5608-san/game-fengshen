# Game Data Inventory

本清单针对提交 `d636453f14f86a096f9d293bf3facfd96cfcb614`。数据库为 `Resources/res/MainData`，20张表、可只读打开。精确表定义、类型、空值统计见 [database-tables.json](evidence/database-tables.json)；地图逐项列表见 [map-catalog.csv](evidence/map-catalog.csv)，覆盖全部259个ID，而非抽样名称。

## 准确度分层

- `REFERENCE_EXACT`：已确认与参考快照逐字节/逐字段一致，**不代表原版准确**。
- `ORIGINAL_VERIFIED`：未来对用户指定 ROM 版本或可定位的原版画面/运行轨迹验证，当前未给任何整表此状态。
- `SUSPECTED_ADDITION`：数据带有改编/工作室/商城等证据，隔离等待比对。
- `UNKNOWN`：缺失或语义尚未确认。TODO 必须绑定字段/ID与验证任务，不能自动填0。

所有现有素材的再分发许可证状态为 UNKNOWN（SQLite 单独记录）。每次转换保留 commit、文件 SHA-256、表/主键或地图图层/格子坐标，以及转换器版本。

## 音频

52个MP3均可探测时长、采样率、声道与码率，详见 [asset-probes.json](evidence/asset-probes.json)。文件为23首bgm及29个sound编号，无完整曲名、场景/技能音效绑定表、采样来源和循环点说明。

不能将MP3文件存在写成“原版音乐完整”。后续对照：曲目→原版场景→输入时间点→循环起终点→淡入淡出/抢占行为；音效至少覆盖确认、取消、脚步或移动、受击、法术、胜利等实际存在的类别。类别存在与否以原版为准。

## 最大缺口

1. 原版真实性基准：ROM版本、hash、是否汉化/修改版、原版区域/剧情/物品总目录。
2. 战斗/遇敌：伤害、整数截断/溢出、命中/暴击/连击、速度排序、AI、掉落、逃跑、RNG与计步。
3. 事件语义：Flag读写与哨兵值、队员加入/离开、分支、切图/战斗完成后的续执行、特殊法宝/地形变化。
4. 内容差异：复刻库中的工作室/额外地图/商城/技能与装备改动；数值不能因名称相同就认定忠实。
5. 原版中文字库、色板、精确分辨率/画面窗口、动画帧时序、APU音频与循环。
6. 可运行的核心与可靠本地存档。这是程序缺口，不应靠编造更多数据弥补。
