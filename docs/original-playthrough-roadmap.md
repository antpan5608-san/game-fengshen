## v11 A 检查点的事件与装备对照（API 35 x86_64 模拟器）

仆人事件触发对象为地图 114 的 ROM NPC index 2；Android 当前静态位置 `(11,23)`，角色上下左右邻格按 A 或直接点选。无赠刀前置条件，首谈 ROM dialogue group 124/message 6，复谈 message 7。首谈完整结束时背包 `rom.item.0` 增加 1、写入一次性互动标志；中途关闭不领奖，复谈不再增加。目标 ROM 冷启动正常按键记录在 `private-derived/equipment-probe-final/`，取证与哈希见 `game-data/provenance/equipment-opening.json`。ROM 帧 649 的 `05D0` 赠刀、帧 1232 的 `0560=FF`/`0548=0` 卸装、帧 1980–1981 的重装，是该局部效果的依据；`6818/6819` 是事件脚本指针，不是背包。初始哪吒右手 ID 0、背包小刀 0、最大 MP 0；赠刀后背包 1，卸装后 2，重装后 1。右手小刀只给哪吒 +2 攻击，装备槽占用时不替换；其他装备、道具效果未放开。原版 NPC 走位和赠刀 flag 的具体内存写入仍待核，Android 的静态 NPC 与标志存档是当前开发范围。

v11 `opening-segment-001-c4` 由原有导出脚本、`ContentLoader` 和 `SaveSnapshot` 消费；旧 `c1`/`c2`/`c3` 本地存档迁移到 ROM 物品稳定 ID。Android 模拟器从清空应用数据的正常启动，经摇杆走到仆人、对话获刀、卸装/重装、南侧出口到地图 16，录屏 `artifacts/checkpoint-ui/fengshen-v11-opening-emulator.mp4`，未使用调试传送或修改状态。卸装/重装后的攻击和背包显示已目视核对；Android 仪器测试验证进程重启后的存档。云存档服务扩充 `maxMp` 和 `equipment` 可选字段，旧存档仍可读取，模型回传测试与线上服务健康/登录读回通过；此次未用真实一加 13T 验收。
