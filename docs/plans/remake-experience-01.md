## 当前有效整体目标

**原版剧情与规则完整可玩，整体画面和操作体验达到参考《封神榜 伏魔三太子（重制版）》的水平，覆盖战斗、角色、物品、商店、对话及探索交互。**

“参考水平”指呈现质量和可玩体验，保留之前人类选择的原版规则、画面/动画升级。商业参考图片仅供研究，不直接发布；本次没有批准技能树、必杀值、ATB/速度条、合成、额外角色、自动战斗或加速，不改变原成长、伤害、回合顺序、物品规则、剧情与旧档。以后只有人类新增授权才调整玩法范围。

复用 BATTLE-VISUAL-02 的素材配置、加载、动作系统及现有地图绘制；原格网、碰撞、入口、返程、交互位置与条件不因高分辨率图片改变。所有 UI 来自真实状态，不保存第二份背包、HP、MP 或剧情。沿用免费或自行制作素材的来源、版本、hash、许可/生成及加工记录；默认无新增购买依赖和逐链接批准流程，参考截图不做发布素材。按既定当前必要解码、64 MiB 图像缓存和设备性能要求实现。

## 约束二：尽早交付可见的完整可玩片段

保留当前 v90 收尾与冻结验收。在下一个安全规划版本优先完成真实正常可玩的新视觉流程：**现有原版起始局部剧情 → NPC 谈话/宝箱或已证隐藏调查 → 物品使用 → 进入战斗 → 攻击与已实现治疗演出 → 奖励 → 保存与外部冷启恢复**。只用已有取证功能、真实合法持有物与角色，不捏造宝箱、治疗习得、入队或奖励，不把受控 fixture 称为正常剧情。

四人新战场、站位、大字和 Boss 另行实际 App 验收，与正常起始片段分开。尚未完成的正常四人主线不是初始视觉交付前置；先用已验证攻击和治疗闭环接演出，无需等待全部26法术或全世界取证才展示。角色尚未合法学会/入队时不为测试开放能力，已实现法术依真实角色和状态验证。后续仍由唯一写入者按主线阻断和实际依赖自主安排，个别未知规则只阻塞依赖项，不打断当前候选。

每个规划版本真实验收后沿原流程发布，交付实际 App 截图、原录像、状态与限制。素材生成、CPU/JVM、合成传输 fixture 或小范围 UI 修正不代表完整片段或全部视觉完成。当前冻结候选的源码不被新文档改变：本地登记此补充，候选发布后再同步文档提交与下一版代码。

## 约束三：视觉和体验成为长期完成硬条件

最终除原版规则、存档安全与正常新游戏至结局，还必须真实验收参考水平的整体表现：

- 角色、环境风格一致；战场比例、行动者和目标清楚。
- 攻击、法术、受击、死亡、胜利/失败动画连续；群体效果只覆盖真实目标，动画不采 RNG、不扣费、不结算奖励、不写存档。
- 物品名称、图标、用途、目标、消耗、条件可理解，能力真实可用；装备、商店、对话、探索和交互体验一致。
- 字体 1/1.3/2 可读；单至四人、多敌、同类实例、Boss 不遮挡；至少48dp触摸目标，实际手机操作、帧耗时、内存按既定标准测量，一加13T目标60fps不以估计代替实测。
- 必须实际看 App 截图、录像和手机操作效果；纯几何、编译、素材存在或自动门禁成功不关闭视觉/体验项。真机缺失明确 PENDING，继续独立开发；受控边界不冒称正常故事流程。
- 同指令和同 RNG 下，新旧呈现的 HP、MP、状态、库存、金钱、经验、奖励和旗标完全一致，不重复结算，不牺牲旧存档兼容。
