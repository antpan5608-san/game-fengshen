# 战斗画面与动画升级方案：参照所示复刻版，保留原版规则

## 1. 搜索结果与目标

您提供的画面与艾露比工作室《封神榜 伏魔三太子（重制版）》官方截图高度匹配：哪吒头像、蓝色状态面板、右侧角色站位及“自动／加速”按钮使用同一套视觉样式。[官方页面](https://store.steampowered.com/app/1765160/)

按您选择，保留原版回合、伤害、法术习得、剧情和存档规则。本次范围为画面与动画，参考版的速度条、技能树、必杀值及自动战斗不纳入本批。

## 3. 画面、动画与接口改动

- **战场：**完整背景覆盖战斗安全区域，敌左我右；四名队员斜向排列，脚底对齐地面。默认字体下战场至少占有效高度的一半。
- **场景：**按原版地图环境建立背景映射。首批覆盖草地、海岸、海底与洞穴，后续覆盖已开放场景；原版黑场使用相应暗色环境。
- **角色：**制作四名主角的独立头像与战斗图集，包含待机、攻击、施法、受击、倒地和胜利动作。敌人保留原版可识别形态，普通敌人与 Boss 使用不同尺寸预算。
- **状态与指令：**底部显示一至四人头像、姓名、HP／MP 数值及短血条；宽屏四人单排，大字体采用两排。当前角色明确高亮，指令面板放在战场下缘，避免遮挡角色和目标。
- **目标：**血条贴近对应敌人；同类敌人用实例编号区分。继续“先动作、后目标”，选择时显示轮廓和目标提示，查看信息不消耗行动。
- **演出：**攻击采用准备、前进或投射、命中、返回；治疗采用柔和光效，伤害采用局部反馈、飘字和轻微震动，死亡采用淡出或倒地。群体法术覆盖真实目标范围，未实现法术继续保留不可用说明。
- **接口：**在现有内容加载器增加按稳定角色／敌人编号绑定的视觉配置，包括背景、头像、图集、脚底锚点和动作映射；在现有行动快照补充必要的法术及表现标识。
- **执行隔离：**沿用现有 `BattlePresentation` 与 Canvas。动画只读取已计算的行动快照，不调用随机数、不扣 MP、不修改奖励或保存状态；绘制与触摸共用布局。
- **加载：**只加载当前战斗需要的素材，解码图像缓存上限为 64 MiB。缺失素材回退现有图形并登记欠账，不阻断剧情，也不视作美术完成。

参考图两侧的 ENTER、ESCAPE 和虚拟方向键属于运行外层的样式，本项目继续采用原生触摸操作。
