## 安装

1. 手机打开[已验证下载链接](https://kubernetes-fleetpilot.oss-cn-beijing.aliyuncs.com/artifacts/fengshen-remake/app/fengshen-remake.apk.bin?v=1)，保存后去掉末尾 `.bin`，将文件名改为 `fengshen-remake.apk`，使用系统文件管理器打开并按系统提示允许该来源安装；它是Debug操作验证版。也可将本地 `artifacts/checkpoint-a/fengshen-operation-a-debug.apk` 复制到手机安装。
2. 或在USB调试已开启且设备授权后执行：

```powershell
adb devices -l
adb -s <OnePlus设备序列号> install -r F:\apps\fengshen-remake\artifacts\checkpoint-a\fengshen-operation-a-debug.apk
```

3. 打开“封神 · 操作验证 A”，横屏。首次Android全屏提示若出现，确认后进入场景。本版不要求联网、登录或下载ROM。
4. 首次位置(8,21)。画面紫线是开发开放范围，暗区仅静态显示；不是原版墙体或任务限制。A/B只有按下反馈，NPC/出入口/战斗暂不开放。
